# Aldk Light

Управление RGB-лампами с Windows по Bluetooth — замена приложению SymphonyLight.

Лампы подключены к общему контроллеру `JTX-HC`. От USB он берёт только питание,
управление идёт по Bluetooth LE, поэтому компьютеру нужен Bluetooth-адаптер.

## Запуск

Готовая программа — один файл `dist\AldkLight.exe`, Python для неё не нужен.
Её можно скопировать куда угодно. Ключ `--tray` запускает свёрнутой в трей.

Контроллер держит одно подключение. Если лампы не находятся — закройте SymphonyLight
на телефоне (или выключите на нём Bluetooth): пока телефон подключён, контроллер не виден.

## Возможности

| Раздел | Что делает |
| --- | --- |
| Цвет | Постоянный цвет: поле «оттенок × насыщенность» и готовые цвета |
| Эффекты | 58 встроенных анимаций контроллера, скорость и направление |
| Экран | Мониторы делятся на участки, лампы берут преобладающий оттенок картинки |
| Музыка | Яркость следует за басами звука компьютера, цвет меняется на ударах |
| Настройки | Автозапуск с Windows, автоматическое включение по солнцу (закат — рассвет) или по часам, гашение ламп при выходе |

Ползунок яркости и кнопка питания общие для всех режимов. Крестик сворачивает окно в трей,
выход — через меню значка. Повторный запуск не создаёт второй экземпляр, а показывает окно первого.

### Ограничение: один цвет на обе лампы

В протоколе контроллера нет команды, задающей цвет отдельному участку ленты, — цвет всегда
один на весь контроллер (см. разбор официального приложения в
[nukemberg/cheap-leds](https://github.com/nukemberg/cheap-leds/blob/HEAD/PROTOCOL.md)).
Поэтому «левая лампа — левый монитор, правая — правый» с одним контроллером невозможно.
Проверено и на железе: во всех четырёх музыкальных режимах контроллера, с потоком цветов и
с его собственным микрофоном, лента остаётся одного цвета по всей длине.
Обходной вариант — «Экран → По очереди»: картинка делится на три части слева направо,
и лампы плавно переливаются между их цветами.
Режим «Экран» уже считает цвета по участкам каждого монитора отдельно, так что при появлении
второго контроллера останется только привязать лампу к монитору.

## Разработка

```bash
python -m venv .venv
```

```bash
.venv\Scripts\python -m pip install -r requirements.txt
```

Запуск из исходников — `run.bat`, тесты:

```bash
.venv\Scripts\python -m unittest discover -s tests
```

Сборка exe (результат в `dist\AldkLight.exe`):

```bash
build.bat
```

Интерфейс — одна страница `aldk_light/web/index.html`. Её можно открыть в обычном браузере
с параметром `?mock` и править вёрстку без ламп.

## Протокол

Пакеты пишутся в характеристику `FFF3` сервиса `FFF0`, формат `BC <команда> <длина> <данные> 55`:

| Действие | Пакет |
| --- | --- |
| Включить / выключить | `BC 01 01 01 55` / `BC 01 01 00 55` |
| Оттенок 0..359°, насыщенность 0..1000 | `BC 04 06 <отт ст> <отт мл> <нас ст> <нас мл> 00 00 55` |
| Яркость 0..1000 | `BC 05 06 <ст> <мл> 00 00 00 00 55` |
| Эффект | `BC 06 02 00 <номер> 55` |
| Направление эффекта | `BC 07 01 <00 прямое / 01 обратное> 55` |
| Скорость эффекта 1..100 | `BC 08 01 <скорость> 55` |

Режимы «Экран» и «Музыка» шлют пару «яркость `05` + цвет `04`» 30 раз в секунду.

Команда `09` («поток цвета с микрофона телефона», `BC 09 06 <отт> <нас> <xx xx> 55`) не используется.
Она красит всю ленту целиком, а её последние два байта яркостью не являются: проверено на лампах,
что и белый, и розовый остаются на полной яркости при любом значении. Яркость задаёт только `05` —
она действует и в обычном режиме, и в потоковом.

Питание, яркость и цвет проверены на лампах побайтно. Команды `02` (порядок цветовых каналов)
и `03` (число светодиодов) меняют постоянные настройки контроллера — приложение их не отправляет.
Сервис `5833ff01-…` — обновление прошивки, приложение его не трогает.

## Файлы

- `aldk_light/protocol.py` — сборка пакетов и список эффектов
- `aldk_light/ble.py` — подключение, переподключение, отправка без накопления очереди
- `aldk_light/engine.py` — режимы, источники цвета, расписание
- `aldk_light/screen.py` — участки экрана и преобладающий цвет
- `aldk_light/fade.py` — плавный переход цвета между кадрами (30 шагов в секунду, пакеты без подтверждения)
- `aldk_light/audio.py` — уровень звука компьютера
- `aldk_light/schedule.py`, `aldk_light/autostart.py` — расписание по часам и автозапуск
- `aldk_light/sun.py` — закат и рассвет по координатам (формулы NOAA, без сети), список городов
- `aldk_light/app.py` — окно, трей, защита от второго экземпляра
- `aldk_light/web/index.html` — интерфейс
- Настройки и журнал: `%APPDATA%\AldkLight\`
